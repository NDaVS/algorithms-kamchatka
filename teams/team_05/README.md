# Команда № 5

## Название команды
Снегоплан

## Участники
- Козлов Георгий Александрович — разработчик — GitHub

## Решение
Прототип системы планирования снегоуборки для Петропавловска-Камчатского, который сокращает холостой пробег техники. Граф дорог строится из OpenStreetMap и учитывает уклоны улиц. Маршруты плугов и самосвалов строятся по районам, при поломке или новой заявке план пересчитывается. Работа видна на экране диспетчера с картой всех маршрутов и на экране водителя. Вся техника заканчивает смену на снегоотвале за городом.

## Как запустить
Нужны Windows, Python 3.11+ и Node.js 20+. Из папки `teams/team_05`:

```bat
setup.bat
run.bat
```

`setup.bat` устанавливает зависимости. `run.bat` запускает сервер и открывает http://localhost:5173/dispatcher. Экран водителя открывается по адресу http://localhost:5173/driver?v=П-01. Данные карты уже лежат в `backend/data`. Чтобы скачать их заново, запустите `prepare_data.bat`.
