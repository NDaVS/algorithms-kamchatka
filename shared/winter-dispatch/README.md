# Алгоритмы Камчатки

Переносимая система планирования, диспетчеризации и контроля зимнего содержания города. Первый полигон — Петропавловск-Камчатский. Базовый планировщик смены работает на синтетическом сценарии.

## Запуск

Из корня общего репозитория перейдите в каталог прототипа командой `cd shared/winter-dispatch`.

**Для показа** откройте [диспетчерскую](demo/index.html) в браузере. Машины, задания и журнал работают на одном экране с реальными улицами Петропавловска-Камчатского. [Геоданные и импорт](data/README.md) · [Сценарий смены](docs/DEMO.md).

Для общей базы смен из корня проекта запустите `python3 workspace_server.py` и откройте [локальную диспетчерскую](http://127.0.0.1:8765/). Для пересчёта B0/O1 установите зависимости из `requirements-core.txt`. Откройте **ДЕМО** для сравнения планов, запуска показа с событиями и принятия плана в отдельную смену. [Инструкция](docs/INTEGRATED_PLANNER.md) · [Хранение и перенос на сервер](docs/WORKSPACE.md).

Отдельные проверки Python-планировщика запускаются из корня проекта с Python 3.10 или новее, без внешних зависимостей:

```sh
python3 planner.py scenarios/demo-shift.json --variant normal
python3 planner.py scenarios/demo-shift.json --variant road-closed
python3 planner.py scenarios/demo-shift.json --variant vehicle-unavailable
```

Команда выводит JSON с назначениями, причинами пропусков, событиями и метриками. [Сценарий и допущения](docs/SHIFT_SCENARIO.md).

## Данные для исследования

[Реестр закупок и техники](docs/EIS_REGISTER.md) содержит выборки по открытым карточкам ЕИС и скрипты сбора. Диспетчерская запускается независимо от этого реестра.
